# CW Decoder 4

無線機の音声出力をつなぐだけで、モールス信号 (欧文 / 和文) を読み取って液晶に表示する CW デコーダです。
安価な ESP32 ボード「CYD」1 枚で動作します。現在のバージョンは `v3.7` です。

<img src="docs/images/front.jpg" width="480" alt="CW Decoder 4 の外観">

使い方は **[取扱説明書](docs/manual.md)**、デコードの仕組みは **[デコードアルゴリズム](docs/decoder.md)** を参照してください。
CH32V003 / CH32V006 (UIAPduino) 版は [UIAP_CWDecoder2](https://github.com/pokibon3/UIAP_CWDecoder2) にあります (デコード処理は共通です)。

## 特徴

- **大型表示**: 2.8inch のカラー LCD に、デコードした文字を 16 文字 × 6 行の大きな文字で表示します。スペクトラムとオシロスコープも同じ画面に並び、操作はタッチパネルで行います
- **マイク入力**: マイクを内蔵しているので、無線機のスピーカーの音をそのまま拾ってデコードできます。AUDIO IN にケーブルをつなげば、自動でライン入力に切り替わります
- **高ノイズ耐性**: 受信周波数の両脇も同時に測り、スペクトルの広がりでトーンとノイズを見分けます。
  NR (Noise Reduction) 機能でトーンを強調するので、ノイズに埋もれかけた弱い信号も拾えます
- **自動調整機能**: 受信周波数・速度 (4〜50WPM)・判定のしきい値を自動で合わせます。面倒な調整は要りません
- **スペクトラム表示**: デコード中の周波数範囲をスペクトラムの上に示します。信号をタップすれば、その周波数に受信を合わせられます
- **オシロスコープ表示**: デコードの過程を 3 つの表示で見せるので、どの信号がどう読まれたかが一目で分かります
  - `RAW`: 入力された音声の波形 (ノイズを含む)
  - `ENV`: 受信周波数の成分だけを取り出した強さ
  - `KEY`: 抽出したマーク / スペースと、デコードした文字
- **世界時計**: パタパタ時計で 12 か国の時刻を表示します。夏時間の計算も、ネット経由の時刻合わせも自動です (要 Wi-Fi 設定)
- **ファームウェアの自動更新**: 新しい版が公開されると起動時にお知らせし、ワンタッチで更新できます (要 Wi-Fi 設定)

## 対応ハードウェア

2.8inch の CYD (Cheap Yellow Display) 系ボードで動作します。CYD は、液晶とタッチパネルを備えた安価な ESP32 ボードです。
液晶のコントローラには **ST7789** と **ILI9341** の 2 種類があり、それぞれ専用のファームウェアを用意しています。

- ESP32 (esp32dev)
- LCD (Liquid Crystal Display): 2.8inch 240x320、ST7789 または ILI9341
- タッチパネル: XPT2046

## ハード接続

CYD には、専用のアナログボード ([回路図](docs/schematic.pdf)) をつないで使います。
アナログボードは、無線機の音声を 700Hz のバンドパスフィルタで帯域制限し、1.65V のバイアスを加えて CYD に渡します。
CYD への電源 (5V) も、アナログボードから供給します。

| アナログボード (J3) | CYD |
|---|---|
| OUT | GPIO35 (音声入力) |
| 5V | VCC (5V) |
| GND | GND |

無線機の音声出力は、背面の AUDIO IN に 3.5mm プラグでつなぎます。つなぐと内蔵マイクは OFF になります。
背面の端子の並びは [取扱説明書](docs/manual.md#各部の名称) を参照してください。
入力レベルは、ボリュームで FFT パネルのレベルメーターが黄色の目盛 (−5 dBFS) を超えない程度に調整してください。

### 電源

- 電源電圧は DC 9〜12V で、アナログボードの DC ジャック (外径 5.5mm / 内径 2.1mm、センタープラス) から入力します
- 9V・1A 程度の AC アダプタを推奨します
- CYD の USB Micro-B 端子からも給電できます

## ビルド

VS Code + PlatformIO でビルドします。environment は液晶のコントローラごとに分かれています。

| environment | コントローラ |
|---|---|
| `esp32dev` | ST7789 |
| `esp32dev_ili9341` | ILI9341 |

```sh
pio run -e esp32dev -t upload           # ST7789 のボード
pio run -e esp32dev_ili9341 -t upload   # ILI9341 のボード
```

コントローラと合わないファームウェアを書き込むと、表示とタッチが上下逆になります。
どちら用のファームウェアかは、起動時のシリアル出力 (115200bps) の `[lcd] panel = ...` で確認できます。

v2.0 以前の本体は、パーティション構成が異なるため、最初の 1 回だけ USB で書き込んでください。

## 関連ツール

### USB 書き込みツール

<https://pokibon3.github.io/cw_decoder4/flasher/>

ブラウザから USB 経由でファームウェアを書き込むツールです。開発環境のインストールは不要で、
Mac / Windows の Chrome または Edge で動作します。主な用途は次のとおりです。

- 過去の版への書き戻し (v2.4 以降)
- 設定の初期化 (タッチ位置の調整に失敗して操作できなくなったときなど)
- フラッシュメモリの全消去

接続時に本体の版と液晶のコントローラを読み取り、合わないファームウェアを選ぶと警告します。

### スコープビューア

<https://pokibon3.github.io/cw_decoder4/scope/>

本体のオシロスコープ画面を、PC の大きな画面で再現するツールです。波形・マーク / スペース・デコード結果を
時間を追って確かめられるので、正しくデコードできない原因を調べるのに役立ちます。

SETUP の `ログ出力` を ON にし、USB でつないだ PC の Chrome でこのページを開いて接続します。保存したログの再生もできます。

### 配布用スクリプト

| スクリプト | 内容 |
|---|---|
| `tools/make_release.sh` | 両コントローラ用のファームウェアをビルドし、配布用の bin と自動更新用の目録 (`web/firmware/latest.txt`) を作ります。新しい版を公開するときに使います |
| `tools/make_versions.py` | USB 書き込みツール用に、全版の bin と目録をまとめます。GitHub Pages の公開時に自動で実行されます |

## 変更履歴

各項目の最初の一文は、USB 書き込みツールで版を選んだときの変更の要約にも表示されます。

- V3.7
  - オシロの全幅表示で、右端の表示が乱れる不具合を直しました
  - 下段パネルの境目でダブルタップすると、デコードしなくなることがある不具合を直しました
- V3.6
  - 起動時の更新チェックが、メモリ不足で失敗する不具合を直しました
  - v3.4 / v3.5 の配布を停止しました。この 2 つの版からは、[USB 書き込みツール](#usb-書き込みツール) か SETUP の `FW更新` で一度だけ手動で更新してください
- V3.5 (配布停止)
  - SETUP 画面の項目の並びを整理しました
  - 時刻合わせの画面に、`NTP同期` ボタンと夏時間の切り替えを追加しました
- V3.4 (配布停止。v3.3 の変更を含みます)
  - ALE (Adaptive Line Enhancer) による `NR` を追加しました (既定 ON)
  - 世界時計で選んだ国を、再起動しても覚えておくようにしました
  - ST7789 のボードで、タッチ位置が下にずれる不具合を直しました
- V3.2
  - U と R を続けて送った `UR` (あなたの、の意味) を読めるようにしました
  - CH32V 版へ移植しやすいように、変数どうしの掛け算・割り算をなくしました (デコード結果は変わりません)
- V3.1
  - 符号内のスペースが長い送信で、文字がばらけて E / T だらけになる不具合を直しました
- V3.0
  - TONE を AUTO に戻したとき、1000Hz から動かなくなる不具合を直しました
- V2.6〜V2.9
  - ネット経由のファームウェア自動更新に対応しました
  - SETUP 画面を 2 列にして、項目の名前を整理しました
- V2.5
  - FFT / オシロをダブルタップで横幅いっぱいに表示できるようにしました
  - ノイズだけのときに E / T が出るのを抑えました
- V2.4
  - TONE AUTO が、符号の隙間のノイズに引っぱられて信号から外れる不具合を直しました
- V2.3
  - 時計を世界時計にしました (12 か国、夏時間に対応)
  - ステータス行に `SETUP` ボタンを追加しました
- V2.2.1
  - OTA モードで自宅の Wi-Fi にも同時に接続し、`http://cwdec.local/` から更新できるようにしました
- V2.2
  - ノイズの中で短点と長点がつながるなど、デコードの誤りを減らしました
  - 入力レベルメーターを dB 表示にし、ステータス行に時計を追加しました
- V2.1
  - パタパタ時計と SETUP 画面 (時刻合わせ、Wi-Fi 設定、OTA 更新) を追加しました
  - 表示される周波数と WPM が約 22% 高く出ていた不具合を直しました
  - パーティション構成を変えたので、v2.0 以前からは一度だけ USB で書き込む必要があります
- V2.0
  - ESP32 版として作り直しました (2.8inch 液晶、タッチパネル、FFT / オシロ表示、TONE AUTO)
- V1.0〜V1.9 (CH32V003 / CH32V006 版)
  - OZ1JHM 版をもとに CH32V へ移植し、Goertzel によるトーン検出、ノイズ対策、速度推定の改良を行いました
