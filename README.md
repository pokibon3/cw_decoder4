# CW Decoder 4

無線機の音声出力を接続し、モールス信号 (欧文 / 和文) をデコードして液晶に表示する CW デコーダです。
ESP32 ボード「CYD」と専用アナログボードで構成されます。現在のバージョンは `v3.8` です。

<img src="docs/images/front.jpg" width="480" alt="CW Decoder 4 の外観">

使用方法は **[取扱説明書](docs/manual.md)**、デコードの仕組みは **[デコードアルゴリズム](docs/decoder.md)** を参照してください。
CH32V003 / CH32V006 (UIAPduino) 版は [UIAP_CWDecoder2](https://github.com/pokibon3/UIAP_CWDecoder2) にあります (デコード処理は共通です)。

## 特徴

- **大型表示**: 2.8 インチのカラー LCD に、デコードした文字を 16 文字 × 6 行で表示します。スペクトラムとオシロスコープも同じ画面に表示し、タッチパネルで操作できます
- **マイク入力**: マイクを内蔵しているため、無線機のスピーカー音声を直接入力してデコードできます。AUDIO IN にケーブルを接続すると、自動的にライン入力へ切り替わります
- **高ノイズ耐性**: 受信周波数の両側も同時に測定し、スペクトルの広がりからトーンとノイズを判別します。
  NR (Noise Reduction) 機能では、ALE (Adaptive Line Enhancer、適応型ラインエンハンサ) によってトーンを強調し、ノイズに埋もれた弱い信号を検出しやすくします
- **自動調整機能**: 受信周波数・速度 (4〜50 WPM)・判定しきい値を自動的に調整します。手動調整は不要です
- **スペクトラム表示**: デコード対象の周波数範囲をスペクトラム上に表示します。スペクトラム上の任意の位置をタップすると、その位置の周波数に受信周波数を設定できます
- **オシロスコープ表示**: デコード処理の状態を次の 3 種類の波形で表示し、信号の検出結果を確認できます
  - `RAW`: 入力音声の波形 (ノイズを含む)
  - `ENV`: 受信周波数成分の強度
  - `KEY`: 抽出したマーク / スペースおよびデコード結果
- **世界時計**: 選択した地域の時刻を反転フラップ式で表示し、併せて 12 の国・地域の現在時刻を一覧表示します。Wi-Fi を設定すると、時刻を自動的に同期できます。夏時間設定が ON の場合は、各国の規則に従って夏時間を適用します
- **ファームウェアの自動更新**: Wi-Fi および FW自動更新を設定すると、起動時にファームウェアの更新を確認します。新しいファームウェアがある場合は、画面から更新を実行できます

## 対応ハードウェア

2.8 インチの CYD (Cheap Yellow Display) 系ボードで動作します。CYD は、液晶およびタッチパネルを搭載した ESP32 ボードです。
液晶コントローラには **ST7789** と **ILI9341** の 2 種類があり、それぞれ専用のファームウェアを使用します。

- ESP32 (esp32dev)
- LCD (Liquid Crystal Display): 2.8 インチ、240 × 320、ST7789 または ILI9341
- タッチパネル: XPT2046

## ハード接続

CYD には、専用のアナログボード ([回路図](docs/schematic.pdf)) を接続します。
アナログボードは、無線機の音声を 700 Hz のバンドパスフィルタで帯域制限し、1.65 V のバイアスを加えて CYD に出力します。
CYD への電源 (5 V) もアナログボードから供給します。

| アナログボード (J3) | CYD |
|---|---|
| OUT | GPIO35 (音声入力) |
| 5 V | VCC (5 V) |
| GND | GND |

無線機の音声出力は、背面の AUDIO IN に 3.5 mm プラグで接続します。接続すると、内蔵マイクは OFF になります。
背面の端子の並びは [取扱説明書](docs/manual.md#各部の名称) を参照してください。
入力レベルは、スペクトラムの入力レベルメーターが黄色の目盛 (−5 dBFS) を超えない範囲になるように、ボリュームで調整してください。

### 電源

- 電源電圧は DC 9〜12 V です。アナログボードの DC ジャック (外径 5.5 mm / 内径 2.1 mm、センタープラス) に接続します
- 内部発熱が大きいため、9V/1AのACアダプタを推奨します
- CYD の USB Micro-B 端子からも給電できます

## ビルド

VS Code および PlatformIO でビルドします。PlatformIO 環境は液晶コントローラごとに異なります。

| PlatformIO 環境 | 液晶コントローラ |
|---|---|
| `esp32dev` | ST7789 |
| `esp32dev_ili9341` | ILI9341 |

```sh
pio run -e esp32dev -t upload           # ST7789 のボード
pio run -e esp32dev_ili9341 -t upload   # ILI9341 のボード
```

液晶コントローラに対応していないファームウェアを書き込むと、表示およびタッチ位置が上下逆になります。
使用中のファームウェアに対応する液晶コントローラは、起動時のシリアル出力 (115200 bps) に表示される `[lcd] panel = ...` で確認できます。

ファームウェア v2.0 以前を使用している本体はパーティション構成が異なるため、初回更新時のみ USB 経由でファームウェアを書き込んでください。

## 関連ツール

### USB 書き込みツール

<https://pokibon3.github.io/cw_decoder4/flasher/>

ブラウザから USB 経由でファームウェアを書き込むためのツールです。開発環境をインストールする必要はありません。
macOS または Windows 上の Chrome および Edge で動作します。主な用途は次のとおりです。

- 過去のバージョンへの変更 (v2.4 以降)
- 設定の初期化 (タッチ位置の調整に失敗して操作できなくなったときなど)
- フラッシュメモリの全消去

接続時に本体のファームウェアバージョンと液晶コントローラを読み取り、対応していないファームウェアが選択された場合は警告を表示します。

### スコープビューア

<https://pokibon3.github.io/cw_decoder4/scope/>

本体のオシロスコープ画面を PC 上に再現するツールです。波形・マーク / スペース・デコード結果を
時系列で確認し、デコードに失敗する原因の調査に使用できます。

SETUP の `ログ出力` を ON にし、USB で接続した PC の Chrome からスコープビューアを開いて接続します。保存したログも再生できます。

### 配布用スクリプト

| スクリプト | 内容 |
|---|---|
| `tools/make_release.sh` | 両コントローラ用のファームウェアをビルドし、配布用の bin と自動更新用の目録 (`web/firmware/latest.txt`) を作ります。新しい版を公開するときに使います |
| `tools/make_versions.py` | USB 書き込みツール用に、全版の bin と目録をまとめます。GitHub Pages の公開時に自動で実行されます |

## 変更履歴

各項目の最初の一文は、USB 書き込みツールで版を選んだときの変更の要約にも表示されます。

- v3.8
  - 符号内の短い隙間に雑音が入ると、短点 2 つが 1 つの長点として読み取られる不具合を修正しました (例: I が T になる)
- v3.7
  - オシロスコープの全幅表示で、右端の表示が乱れる不具合を修正しました
  - 下段パネルの境界でダブルタップすると、デコードが停止することがある不具合を修正しました
- v3.6
  - 起動時の更新確認がメモリ不足で失敗する不具合を修正しました
  - v3.4 / v3.5 の配布を停止しました。この 2 つの版からは、[USB 書き込みツール](#usb-書き込みツール) か SETUP の `FW更新` で一度だけ手動で更新してください
- v3.5 (配布停止)
  - SETUP 画面の項目の並びを整理しました
  - 時刻合わせの画面に、`NTP同期` ボタンと夏時間の切り替えを追加しました
- v3.4 (配布停止。v3.3 の変更を含みます)
  - ALE (Adaptive Line Enhancer) による `NR` を追加しました (既定 ON)
  - 世界時計で選択した国を、再起動後も保持するように変更しました
  - ST7789 のボードで、タッチ位置が下にずれる不具合を修正しました
- v3.2
  - 略符号（プロサイン）`UR` のデコードに対応しました
  - CH32V 版へ移植しやすいように、変数間の乗算および除算を廃止しました (デコード結果は変わりません)
- v3.1
  - 符号内のスペースが長い送信で、文字が分割され、E / T として誤検出される不具合を修正しました
- v3.0
  - TONE を AUTO に戻した場合に、1000 Hz から動かなくなる不具合を修正しました
- v2.6〜v2.9
  - ネット経由のファームウェア自動更新に対応しました
  - SETUP 画面を 2 列にして、項目の名前を整理しました
- v2.5
  - FFT / オシロスコープをダブルタップで全幅表示できるようにしました
  - ノイズのみの場合に E / T が表示される現象を抑制しました
- v2.4
  - TONE AUTO が符号間のノイズの影響を受け、信号から外れる不具合を修正しました
- v2.3
  - 時計を世界時計にしました (12 の国・地域、夏時間に対応)
  - ステータス行に `SETUP` ボタンを追加しました
- v2.2.1
  - OTA モードで設定済みの Wi-Fi にも同時に接続し、`http://cwdec.local/` から更新できるようにしました
- v2.2
  - ノイズの中で短点と長点がつながるなど、デコードの誤りを減らしました
  - 入力レベルメーターを dB 表示にし、ステータス行に時計を追加しました

  - 反転フラップ式表示と SETUP 画面 (時刻合わせ、Wi-Fi 設定、OTA 更新) を追加しました
  - 表示される周波数と WPM が約 22% 高くなる不具合を修正しました
