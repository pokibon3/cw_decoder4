# CW Decoder 4

ESP32 ボードで動作する CW デコーダです。現在のバージョンは `v3.7` です。  
使い方は **[取扱説明書](docs/manual.md)**、デコードの仕組みは **[デコードアルゴリズム](docs/decoder.md)** を参照してください。

CH32V003 / CH32V006 (UIAPduino) 版は [UIAP_CWDecoder2](https://github.com/pokibon3/UIAP_CWDecoder2) にあります
(デコードの処理は本リポジトリと共通です)。

## 対応ハードウェア

2.8inch の CYD (Cheap Yellow Display) 系のボードで動きます。CYD は、液晶とタッチパネルの付いた安価な ESP32 ボードです。
液晶のコントローラには **ST7789** と **ILI9341** の 2 種類があり、ファームウェアはそれぞれ別にビルドします。

- ESP32 (esp32dev)
- LCD (液晶ディスプレイ): 2.8inch 240x320、ST7789 または ILI9341
- タッチパネル: XPT2046
- 音声入力: GPIO35

## 機能

### デコーダ

モールス信号 (欧文 / 和文) を音声入力からデコードし、液晶に表示します。下段には FFT のスペクトラムとオシロスコープを表示します。

<img src="docs/images/esp32-decoder.png" width="320" alt="デコーダ画面 (欧文)">&emsp;&emsp;<img src="docs/images/esp32-decoder-jp.png" width="320" alt="デコーダ画面 (和文)">

- **トーン検出**: 受信トーンの周波数と、その両脇の周波数の強さを比べて、トーンかノイズかを見分けます
- **ノイズ低減 `NR(ALE)`**: NR は Noise Reduction、ALE は Adaptive Line Enhancer (適応型ラインエンハンサ) の略です。
  トーンだけを強めて、弱い信号を拾いやすくします
- **しきい値の自動調整**: ノイズの大きさに合わせて動くので、入力の音量によらず同じように受信できます
- **速度の自動追従**: 4〜50WPM (WPM: Words Per Minute = 1 分間に送る語数)
- **TONE AUTO**: 500〜1000Hz で最も強い信号に自動で合わせます

### 世界時計

パタパタ時計 (反転フラップ式の時計) で時刻を表示します。下段のボタンで 12 か国の時刻に切り替えられ、夏時間も自動で計算します。
WiFi を登録しておくと、NTP (Network Time Protocol) で時刻を自動で合わせます。時計の表示中もデコーダは裏で動き続けます。

<img src="docs/images/esp32-clock.png" width="320" alt="時計画面">

### SETUP

WiFi の設定、時刻合わせ、ファームウェアの更新、NR の切り替え、タッチパネルの調整などを行います。
WiFi を登録しておくと、起動時に新しいファームウェアを確認して自動で更新できます。

<img src="docs/images/esp32-setup.png" width="320" alt="SETUP 画面">

## ハード接続

CYD に外からつなぐのは、無線機の音声出力だけです。

| CYD の端子 | 接続先 |
|---|---|
| GPIO35 | 音声入力 (約 1.65V の DC バイアスを与えてください) |
| GND | 音声入力の GND |

入力の大きさは、FFT パネルの入力レベルメーターが黄の目盛 (−5 dBFS) より左に収まる程度にしてください。

## ビルド

VS Code + PlatformIO でビルドします。environment は LCD のコントローラごとに分けてあります。

| environment | コントローラ |
|---|---|
| `esp32dev` | ST7789 |
| `esp32dev_ili9341` | ILI9341 |

```sh
pio run -e esp32dev -t upload           # ST7789 のボード
pio run -e esp32dev_ili9341 -t upload   # ILI9341 のボード
```

コントローラと合わない bin を書き込むと、表示とタッチが上下逆になります。
起動時にシリアル (115200bps) へ `[lcd] panel = ...` と出るので、そこで確認できます。

v2.0 以前の本体を更新するときは、最初の 1 回だけ USB で書き込んでください (v2.1 でパーティション構成を変えたため)。

## 関連ツール

### USB 書き込みツール

<https://pokibon3.github.io/cw_decoder4/flasher/>

本体を USB で PC につなぎ、ブラウザからファームウェアを書き込むツールです。PlatformIO などのインストールは要りません。
Mac / Windows の Chrome または Edge で使えます。次のようなときに使います。

- **過去の版に戻したい**: v2.4〜最新の版から選んで書き込めます
- **設定を初期化したい**: タッチ補正・WiFi・時計の地域などをすべて既定値に戻します。
  タッチ位置がずれて画面から操作できなくなったときにも使えます
- **調子がおかしい**: フラッシュメモリ全体を消去してから書き直せます

接続すると本体の版と LCD のコントローラを読み取り、合わない bin を選ぶと警告します。

### スコープビューア

<https://pokibon3.github.io/cw_decoder4/scope/>

本体のスコープ画面を、PC の大きな画面で再現するツールです。デコードがうまくいかないときに、
信号の波形・キー判定・デコード結果を時間を追って確かめるのに使います。

本体の SETUP で `ログ出力` を ON にし、USB でつないだ PC の Chrome でこのページを開いて接続します。
保存したログを読み込んで再生することもできます。

### 配布用スクリプト

| スクリプト | 内容 |
|---|---|
| `tools/make_release.sh` | 両コントローラ用のファームウェアをビルドし、`tools/v<版>/` に bin を、`web/firmware/latest.txt` に自動更新用の目録 (版数・サイズ・MD5) を書き出します。新しい版を公開するときに使います |
| `tools/make_versions.py` | USB 書き込みツールで選べるように、全版の bin と目録 (版・日付・変更の要約など) をまとめます。GitHub Pages の公開時に自動で実行されるので、ふだんは使いません |

## 変更履歴

各項目の最初の一文は、USB 書き込みツールで版を選んだときの変更の要約にも表示されます。

- V3.7
  - オシロの全幅表示で、右端にゴミが出る不具合を直しました
  - 下段パネルの境目でダブルタップすると、デコードしなくなることがある不具合を直しました
- V3.6
  - 起動時の更新チェックが、メモリ不足で失敗する不具合を直しました
  - v3.4 / v3.5 の配布をやめました。この 2 つの版からは、[USB 書き込みツール](#usb-書き込みツール) か SETUP の `FW更新` で一度だけ手動で更新してください
- V3.5 (配布停止)
  - SETUP 画面の項目の並びを整理しました
  - 時刻合わせの画面に、`NTP同期` ボタンと夏時間の切り替えを追加しました
- V3.4 (配布停止。v3.3 の変更を含みます)
  - ALE によるノイズ低減 `NR` を追加しました (既定 ON)
  - 世界時計で選んだ国を、再起動しても覚えておくようにしました
  - ST7789 のボードで、タッチ位置が下にずれる不具合を直しました
- V3.2
  - U と R を続けて送った `UR` (あなたの、の意味) を読めるようにしました
  - CH32V 版へ移植しやすいように、変数どうしの掛け算・割り算をなくしました (デコード結果は変わりません)
- V3.1
  - 符号内のスペースが長い送信で、文字がばらけて E / T だらけになる不具合を直しました
- V3.0
  - TONE を AUTO に戻したとき、1000Hz から動かなくなる不具合を直しました
- V2.6〜V2.9
  - ネット経由のファームウェア自動更新に対応しました
  - SETUP 画面を 2 列にして、項目の名前を整理しました
- V2.5
  - FFT / オシロをダブルタップで横幅いっぱいに表示できるようにしました
  - ノイズだけのときに E / T が出るのを抑えました
- V2.4
  - TONE AUTO が、符号の隙間のノイズに引っぱられて信号から外れる不具合を直しました
- V2.3
  - 時計を世界時計にしました (12 か国、夏時間に対応)
  - ステータス行に `SETUP` ボタンを追加しました
- V2.2.1
  - OTA モードで自宅の WiFi にも同時に接続し、`http://cwdec.local/` から更新できるようにしました
- V2.2
  - ノイズの中で短点と長点がつながるなど、デコードの誤りを減らしました
  - 入力レベルメーターを dB 表示にし、ステータス行に時計を追加しました
- V2.1
  - パタパタ時計と SETUP 画面 (時刻合わせ、WiFi 設定、OTA 更新) を追加しました
  - 表示される周波数と WPM が約 22% 高く出ていた不具合を直しました
  - パーティション構成を変えたので、v2.0 以前からは一度だけ USB で書き込む必要があります
- V2.0
  - ESP32 版として作り直しました (2.8inch 液晶、タッチパネル、FFT / オシロ表示、TONE AUTO)
- V1.0〜V1.9 (CH32V003 / CH32V006 版)
  - OZ1JHM 版をもとに CH32V へ移植し、Goertzel によるトーン検出、ノイズ対策、速度推定の改良を行いました
