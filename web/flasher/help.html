書き込みツールの使い方 書き込みツールへ戻る

CW Decoder (ESP32 版) の本体を USB で PC につなぎ、ファームウェアを書き込むツールです。 本体の自動更新や SETUP の「FW更新」(WiFi 経由) とは別の手段で、過去の版への書き戻しや、 設定の初期化、WiFi が使えない状態からの復旧に使います。

使えるパソコンとブラウザ

  • Mac または Windows の Chrome か Edge。Safari と Firefox は使えません (USB シリアルに対応していないため)。
  • 本体の USB シリアルは CH340 です。最近の macOS は追加のドライバなしで認識します。 Windows でポートが出てこないときは CH340 ドライバ (WCH) を入れてください。

書き込みの手順

  1. 本体を USB ケーブルで PC につなぎます (充電専用のケーブルは使えません)。
  2. 「ポートを選んで接続」を押し、一覧から本体のポートを選びます。
    一覧に出ないときは「すべてのポートを表示」に印を付けてから押します。
  3. 本体が再起動し、いまの版とパネル (ST7789 / ILI9341) が表示されます。パネルは自動で選ばれます。
  4. 書き込むバージョンを選びます。最新版が選ばれています。選んだ版の変更点が下に出ます。
  5. 設定 (NVS) と消去を選びます (下の表)。ふだんは「設定を残す」のままで構いません。
  6. 「書き込み」を押し、確認の内容を見て OK を押します。1 分ほどかかります。書き込み中は USB を抜かないでください。
  7. 終わると本体が再起動し、「✓ v○○ で起動しました」と出れば完了です。

設定 (NVS) と消去の選び方

選択肢どうなるか使う場面
設定を残すタッチ補正・WiFi・夏時間・時計の地域・NR などはそのままふだんの更新、過去の版への書き戻し
設定を初期化する上の設定をすべて既定値に戻すタッチ位置がおかしくなって画面から操作できないとき、設定をやり直したいとき
フラッシュ全体を消してから書く本体の中身をすべて消してから書く。設定も消える原因のわからない不調のとき

パネル (ST7789 / ILI9341)

本体の LCD の種類です。接続時に本体から読み取って自動で選びます。 違うパネル用を書くと、表示が上下逆になりタッチもずれますが、正しいパネル用で書き直せば元に戻ります。

シリアルモニター

本体が USB に出しているログ (115200bps) を表示します。接続すると自動で始まります。

  • 本体をリセット: 本体を再起動して起動ログを表示します。
  • スコープログを隠す: 本体の「ログ出力」(SETUP) が ON のときに大量に流れる波形データの行を隠します。
  • ログを保存: 表示しているログをテキストファイルに保存します。不具合の報告に使えます。

うまくいかないとき

  • ポートが一覧に出ない: ケーブルが充電専用でないか確認します。Windows はドライバ (上記) を確認します。
  • 「ポートを開けません」と出る: ほかのソフト (Arduino IDE や PlatformIO のシリアルモニターなど) が本体のポートを開いていないか確認し、閉じてから接続し直します。
  • 書き込みで「接続できません」と出る: 本体の BOOT ボタンを押したまま「書き込み」を押し、 「本体に接続中」の表示が出たら離します。
  • 接続後に勝手に切断される: 別の USB ケーブルや、PC 本体のポート (ハブを通さない) で試してください。 本体が起動時に WiFi へつなぐときの電流で、給電が足りずに USB が切れることがあります。
  • タッチ位置がおかしい: 同じバージョンを「設定を初期化する」で書き直すと、タッチ補正が既定値に戻ります。 PC が無いときは、本体の BOOT ボタンを押したまま電源を入れ、2 秒押し続けてもタッチ補正だけを消せます。

アプリとしてインストールする

この書き込みツールは、インストールすると、ブラウザのタブではなく独立したウィンドウのアプリとして開けます。 パソコン (Mac / Windows) の Chrome か Edge で行います (Safari・Firefox は不可)。

いちばん簡単な方法: 画面の「インストール」ボタン

  1. このアプリのページを Chrome か Edge で開きます。
  2. 画面上部 (タイトルの行) の右側に「インストール」ボタンが出ていれば、それを押します。
  3. 確認の画面で「インストール」を押せば完了です。

ボタンが出ていないときは、すでにインストール済みか、ページが古いままです。 キーボードで Mac は Command + Shift + R、Windows は Ctrl + F5 を押して 読み込み直してから、もう一度見てください。それでも出ないときは下のメニューから行います。

メニューから行う方法

ブラウザ操作
Chrome ウィンドウ右上の ︙ (縦に点が 3 つ) を押す → 「キャスト、保存、共有」 → 「ページをアプリとしてインストール」
(Chrome の版によっては ︙ のすぐ下に「○○ をインストール」と出ます)
Edge ウィンドウ右上の … (横に点が 3 つ) を押す → 「アプリ」 → 「このサイトをアプリとしてインストール」

インストールした後

  • Mac は Launchpad や「アプリケーション」フォルダ、Windows はスタートメニューから起動できます。
  • ネットにつながっていなくても開けます (ただし書き込みには、ファームウェアを取りに行くためネット接続が必要です)。新しい版を公開したときは、次にネットにつながった状態で開いたときに自動で入れ替わります。
  • デコーダ・書き込みツール・スコープビューアは別々のアプリです。使うものだけ入れてください。
  • やめるときは、アプリのウィンドウ右上の ︙ (Edge は …) → 「アンインストール」を選びます。
