CW Decoder 4 使い方

説明 無線機の AF 出力 → USB オーディオ I/F が最も確実です (FT8 と同じ配線)。 PC 内部の音は仮想ループバック (macOS: BlackHole / Windows: VB-CABLE) 経由で拾えます。
エコーキャンセル・ノイズ抑制・AGC は自動で無効化し、実際に無効化できたかを下の行に表示します。
ステレオ I/F に片チャンネルだけ繋いでいるときは L+R にしないでください (空き側のノイズで S/N が約 3dB 落ちます)。
説明 WebSDR や動画など、ブラウザの別タブで鳴っている音をそのままデコードします。 共有ダイアログで タブ を選び、タブの音声も共有する を必ず ON にしてください。 (Chrome 系のみ。Safari / Firefox は非対応)
--:-- / --:--
説明 WAV / MP3 などを読み込んでデコードします。同じ音源で何度でも再現できるので、 設定の効き具合を比べるのに使えます。
位置を動かすとデコーダの状態はリセットされます (符号の途中から始まるため)。
説明 ハード無しで動作確認するための内蔵 CW 発生器です。S/N を振ると、 ノイズ下でどこまで読めるかをその場で確かめられます。
