「追従中」を押すと停止して、スライダ・ドラッグ・ホイールで横スクロールできます (もう一度押すと再開)。
  Shift + ドラッグで範囲を選択すると、その区間の要素長 (マーク/スペースの ms と短点長比) を表にして
  クリップボードへコピーできます (誤認識の原因を調べるとき用)。

  

  Web Serial API を使うため Chrome / Edge で file:// か http://localhost から開いてください
  (Safari / Firefox では「ログを開く」での再生のみ利用できます)。
