## 各部の名称

本体は、CYD (Cheap Yellow Display) とアナログボードの 2 枚の基板で構成されています。回路は [回路図](schematic.pdf) を参照してください。

<img src="images/front.jpg" width="480" alt="本体前面">

背面には、左から次の端子が並んでいます。

<img src="images/rear-panel.svg" width="640" alt="本体背面: 左からボリューム、AUDIO IN、AUDIO OUT、電源スイッチ、DC ジャック">

| 名前 | 説明 |
|---|---|
| ボリューム | 入力レベルを調整します |
| AUDIO IN | 無線機の音声出力を 3.5mm プラグで接続します。接続すると内蔵マイクは OFF になります |
| AUDIO OUT | AUDIO IN の音をそのまま出力します。ヘッドホンや外部スピーカーを接続します |
| 電源スイッチ | プッシュ式です。押すたびに電源の ON/OFF が切り替わります |
| DC ジャック | DC 9〜12V を入力します (外径 5.5mm / 内径 2.1mm、センタープラス)。内部発熱が大きいため、9V/1AのACアダプタを推奨します |

AUDIO IN に何も接続していないときは、内蔵マイクで無線機のスピーカーの音を入力します。

CYD の USB Micro-B 端子は、PC と接続して、ファームウェアの書き込みおよびログ出力に使用します。給電にも使用できます。

**入力レベルの合わせ方**: 信号を受信しながらボリュームを回し、スペクトラムの入力レベルメーターが
黄色の目盛 (−5 dBFS) を超えない範囲に調整してください。赤色の範囲または `CLIP` が表示される場合、正しくデコードできません。

## 起動

電源スイッチを押すと起動画面 (スプラッシュ) が表示されます。SETUP の `FW自動更新` が ON で Wi-Fi を
設定済みの場合、起動画面の表示中に時刻の同期とファームウェアの更新確認を行い、進行状況を画面下部に表示します。
完了するとデコード画面に切り替わります。

## 操作方法

### SETUP

デコード画面のステータス行にある `SETUP` ボタンをタップすると、SETUP 画面が表示されます。右上の `戻る` をタップすると、デコード画面に戻ります。

#### Wi-Fi設定 (初回使用時)

本体を接続先の Wi-Fi に接続すると、NTP (Network Time Protocol) による時刻合わせと、ファームウェアの更新確認を自動で行います。
Wi-Fi を設定しない場合、時計にはファームウェアのビルド日時が初期時刻として設定され、ファームウェアの更新確認も行いません。

SSID (Service Set Identifier) とパスワードは、スマートフォン (または PC) のブラウザから入力します。

1. SETUP の `WiFi設定` をタップします。受信を停止し、本体が Wi-Fi のアクセスポイント
   (SSID `CWDEC-OTA` / パスワード `cwdecoder`) になり、下の画面が表示されます。

   <img src="images/esp32-wifi.png" width="320" alt="Wi-Fi設定の画面">

2. スマートフォンのカメラで画面右の **QR コード**を読み取り、表示に従って `CWDEC-OTA` に接続します。
   QR コードを読み取れない場合は、スマートフォンの Wi-Fi 設定で `CWDEC-OTA` を選び、パスワード `cwdecoder` を入力します。
3. 接続すると、「ネットワークにサインイン」の通知 (または自動ポップアップ) から設定ページが表示されます。
   設定ページが表示されない場合は、ブラウザで `http://192.168.4.1/` を開きます。
4. 設定ページに接続先 Wi-Fi の **SSID** と**パスワード**を入力して `保存` をタップします。

   <img src="images/phone-wifi-setup.png" width="240" alt="スマートフォンに表示される設定ページ">

5. 本体の画面に「WiFi設定を保存しました」と表示され、SETUP 画面に戻ります。
   スマートフォンを通常使用する Wi-Fi に再接続してください。

- 本体 (ESP32) は **2.4 GHz 帯の Wi-Fi にのみ**接続できます。5 GHz 専用の SSID は使用できません。
- 設定を取り消す場合は、本体の `キャンセル` をタップします。設定内容を消去する場合は、[初期化](#初期化) を使用します。
- 受信 (デコード) 中は Wi-Fi 通信を行いません。Wi-Fi 通信によるノイズが受信に影響することを防止するためです。

#### FW自動更新

既定値: ON。起動時に数秒間 Wi-Fi に接続し、時刻の同期とファームウェアの更新確認を行います。
新しいファームウェアがある場合は、`新しいファームウェアがあります v3.6 → v3.7` のように表示されます。`更新` をタップすると、ファームウェアを更新して再起動します。
Wi-Fi が未設定の場合、設定が OFF の場合、または接続に失敗した場合は、通常どおり起動します。

**v3.4 または v3.5 を使用している場合**: これらのバージョンでは起動時の更新確認が失敗し (`更新はありません` と表示されます)、
オンラインでは更新できません。[USB 書き込みツール](https://pokibon3.github.io/cw_decoder4/flasher/) か
[FW手動更新](#fw手動更新) で v3.6 以降に更新してください。v3.6 以降では自動更新を使用できます。

#### FW手動更新

ブラウザからファームウェアファイル (.bin) をアップロードして更新します。SETUP の `FW更新` をタップし、確認画面で `開始` をタップすると、
OTA (Over The Air) モードになります。
本体がアクセスポイント (`CWDEC-OTA` / パスワード `cwdecoder`) になるので、スマートフォンまたは PC を接続して `http://192.168.4.1/` から
`firmware.bin` をアップロードします (ファームウェアファイルは GitHub リポジトリの `tools/v<版>/` にあります)。
更新が完了すると再起動します。更新に失敗した場合も、更新前のファームウェアは保持されます。再起動すると、更新前のファームウェアで起動します。
Wi-Fi が設定済みの場合は接続先の Wi-Fi にも同時に接続するため、PC から `http://cwdec.local/` でも更新できます
(LAN 側の IP アドレスは画面の `LAN` 行に表示されます)。

<img src="images/esp32-ota-confirm.png" width="320" alt="OTA モードに入る前の確認画面">&emsp;&emsp;<img src="images/esp32-ota.png" width="320" alt="OTA モードの画面">

左図は確認画面、右図は OTA モードの画面です。スマートフォンとの接続方法は [Wi-Fi設定](#wi-fi設定-初回使用時) と同じです。
iPhone のサインイン画面でファイルを選択できない場合は、Safari で開いてください。

#### 時刻合わせ

▲▼で年月日および時刻を設定し、`決定` をタップします。本体には RTC (Real Time Clock) がないため、電源を切るとファームウェアのビルド日時に戻ります。

<img src="images/esp32-timeset.png" width="320" alt="時刻合わせ画面">

- `夏時間`: 世界時計に夏時間を適用するかを切り替えます (ON の場合は各国の規則に従って自動で切り替えます)
- `NTP同期`: 直ちに NTP で時刻を合わせます (Wi-Fi を設定していない場合は操作できません)

#### NR(ALE)

既定値: ON。ON にすると ALE (Adaptive Line Enhancer) でトーンを強調し、
弱い信号を検出しやすくなり、ノイズによる誤表示も減ります ([デコードアルゴリズム](decoder.md#nr-noise-reduction-機能) 参照)。

#### タッチパネル調整

1. `開始` をタップします。`既定に戻す` をタップすると、調整値を消去して既定値に戻します。

   <img src="images/esp32-touchcal.png" width="320" alt="タッチパネル調整の開始画面">

2. 画面の四隅に順に表示される十字の中心をタップします。先端の細い器具を使用すると、正確に調整できます。

   <img src="images/esp32-touchcal-cross.png" width="320" alt="十字の画面">

3. 確認画面で、印の中心を順にタップします。3 点すべてのタップが認識されると、`保存` を操作できるようになります。
   タップが正しく認識されない場合は、`やり直す` をタップしてください。45 秒以内に 3 点すべてのタップが認識されない場合は、調整値を保存せずに SETUP 画面に戻ります。

   <img src="images/esp32-touchcal-verify.png" width="320" alt="調整の確認画面 (3 点ともタップしたところ)">

**調整に失敗し、タッチ操作ができなくなった場合**: [USB 書き込みツール](https://pokibon3.github.io/cw_decoder4/flasher/) の「設定を初期化」で既定値に戻すことができます (Wi-Fi など、ほかの設定も初期化されます)。

#### 初期化

設定した SSID / パスワードを消去し、NTP 同期を停止します。

#### ログ出力

既定値: ON。オシロスコープの表示データを USB シリアル (115200 bps) に出力します。
[スコープビューア](https://pokibon3.github.io/cw_decoder4/scope/) を Chrome で開くと、PC でオシロスコープ画面を再現できます。
デコードには影響しないため、通常は ON のまま使用できます。

バージョン / ビルド日時 / 液晶コントローラ / 起動領域 / Wi-Fi / NTP の同期状況を表示します。

### デコード画面

- `US`/`JP` をタップすると、欧文 / 和文が切り替わります
- `TONE` をタップすると、AUTO → 600 → 700 → 800 → 900 → 1000 Hz の順に切り替わります。
  AUTO (緑色で表示、既定) では、500〜1000 Hz の範囲で最も強い信号に自動調整します
- スペクトラムをタップすると、タップした位置の周波数に受信周波数を設定します (AUTO は解除されます)
- オシロスコープの `RAW` / `ENV` / `KEY` をタップすると、それぞれの表示が ON/OFF になります
- スペクトラム / オシロスコープを**ダブルタップ**すると、対象のパネルを全幅で表示します (再度ダブルタップすると元の表示に戻ります)

  <img src="images/esp32-fft-wide.png" width="320" alt="スペクトラムの全幅表示">&emsp;&emsp;<img src="images/esp32-scope-wide.png" width="320" alt="オシロスコープの全幅表示">

- `SETUP` をタップすると、SETUP 画面が表示されます
- 文字エリアの中央付近をタップすると、時計画面に切り替わります

タッチ位置と反応位置がずれている場合は、[タッチパネル調整](#タッチパネル調整) で調整してください。

### 時計画面

時計画面を表示している間も、デコードを継続します。デコード画面に戻ると、その間に受信した文字が表示されます。

- 国のコードをタップすると、反転フラップ式表示・日付・デコード画面の時計が、その国の時刻に切り替わります (選択した国は電源を切っても保持されます)
- 反転フラップ式表示をタップすると、デコード画面に戻ります

| コード | 国 / 地域 | 標準時 | 夏時間 |
|---|---|---|---|
| `ZL` | ニュージーランド | UTC+12 | 9月最終日曜〜4月第1日曜 |
| `VK` | オーストラリア東部 | UTC+10 | 10月第1日曜〜4月第1日曜 |
| `JA` | 日本 (既定) | UTC+9 | なし |
| `BY` | 中国 | UTC+8 | なし |
| `VU` | インド | UTC+5:30 | なし |
| `UA` | ロシア (モスクワ) | UTC+3 | なし |
| `DL` | ドイツ (欧州中部) | UTC+1 | 3月最終日曜〜10月最終日曜 |
| `UTC` | 世界標準時 | UTC | なし |
| `LU` | アルゼンチン | UTC−3 | なし |
| `W1` | 米国東部 | UTC−5 | 3月第2日曜〜11月第1日曜 |
| `W6` | 米国西部 | UTC−8 | 同上 |
| `KH6` | ハワイ | UTC−10 | なし |

夏時間は [時刻合わせ](#時刻合わせ) の `夏時間` が ON のときだけ適用します。

#### 時刻の同期

Wi-Fi が設定済みの場合、次のタイミングで NTP による時刻合わせを自動で行います。

- 起動時 (FW自動更新が ON の場合)
- 時計画面の表示時 (前回の同期から 24 時間以上経過している場合に同期します。同期に失敗した場合は、1 時間後に再試行します)

同期中の数秒〜20 秒間はデコードを停止します。デコード画面では Wi-Fi 通信を行いません。
手動で時刻を合わせる場合は、[時刻合わせ](#時刻合わせ) の `NTP同期` を使用します。
