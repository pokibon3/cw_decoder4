# CW Decoder 4 (ESP32 版) 取扱説明書

ESP32 ボード (2.8inch CYD 系) で動く CW デコーダの使い方です。
対象はファームウェア v3.4 です。仕組み・ビルド・配布の説明は [README](../README.md) にあります。

画面の写真は [PC シミュレータ](../README.md#pc-シミュレータ-sim) で撮ったもので、
実機と同じ描画コードの出力です (時刻などは撮った時点のもの)。

- [起動](#起動)
- [画面の見方](#画面の見方)
- [SETUP](#setup) — まず [WiFi設定](#wifi設定-最初に行ってください) を行ってください
- [操作](#操作)
- [時計画面](#時計画面)
- [時刻の同期](#時刻の同期)

## 起動

電源を入れると起動画面 (スプラッシュ) が出ます。SETUP の `FW自動更新` が ON で WiFi を
登録してあれば、この間に時刻の同期とファームウェアの新版チェックを行い、状況を最下段に出します。
終わるとデコーダ画面になります。

<img src="images/esp32-splash.png" width="320" alt="起動画面 (スプラッシュ)">

## 画面の見方

<img src="images/esp32-decoder.png" width="320" alt="デコーダ画面 (欧文)">&emsp;&emsp;<img src="images/esp32-decoder-jp.png" width="320" alt="デコーダ画面 (和文)">

左が欧文、右が和文 (JP モード)。和文の `「` `」` は「ホレ」「ラタ」(和文の開始・終了) の表示です。

- 最上段: ステータス行 (`US`/`JP`、`TONE` (AUTO/600〜1000)、`SETUP` の各ボタン、xxWPM、
  右端に時計 HH:MM:SS = 世界時計で選択中の国の時刻)
- 上 2/3: デコード文字エリア 16列 x 6行 (24x24 全角フォント、英数字も全角表示、和文カタカナ対応、濁点/半濁点は自動合成)
- 下 1/3 左: FFT スペクトラム (ヘッダに入力レベルメーター: dB スケール −50〜0 dBFS、0 dBFS = ADC 半スイング ≈ 1.55V ピーク。
  黄の目盛 −5 dBFS ≈ 0.85V ピークが ADC の直線範囲の上限、−2.5 dBFS 以上は赤、レール到達で `CLIP` 表示) (約300〜1200Hz、1bin=31.25Hz のライン表示、ピークホールド、TONE 選択レンジ 600〜1000Hz のガイド帯 + 選択トーンの検出帯域(±34Hz)表示)
- 下 1/3 右: オシロスコープ (約3.6秒スパン。生波形 min/max バンド + トーンエンベロープ + キー判定を同一時間軸で色分け重畳。
  キー判定バーの上には、デコードされた文字がその符号の中央位置に表示され、掃引とともに左へ流れる。
  `KEY` ボタンで判定バーと文字を一緒に ON/OFF)

## SETUP

デコーダ画面のステータス行にある `SETUP` ボタンを押すと SETUP 画面になります。
項目は 2 列に並びます。右上の `戻る` でデコーダ画面に戻ります。

<img src="images/esp32-setup.png" width="320" alt="SETUP 画面">

```
WiFi設定          時刻合わせ
FW更新            FW自動更新: ON
NR(ALE): ON       ログ出力: ON
タッチパネル調整  初期化
                  About
```

### WiFi設定 (最初に行ってください)

本体を自宅の WiFi につないでおくと、次のことが自動で行われます。WiFi を登録しないと、
時計はビルドした日時から始まり、ファームウェアの更新も確かめません。

- 起動時の**時刻合わせ** (NTP) と**ファームウェアの新版チェック** ([FW自動更新](#fw自動更新))
- 時計画面を表示している間の、1 日 1 回の時刻合わせ ([時刻の同期](#時刻の同期))

本体にはキーボードが無いので、SSID とパスワードはスマホ (または PC) のブラウザから入力します。

1. SETUP の `WiFi設定` を押します。受信を止め、本体が WiFi のアクセスポイント
   (SSID `CWDEC-OTA` / パスワード `cwdecoder`) になって、下の画面が出ます。

   <img src="images/esp32-wifi.png" width="320" alt="WiFi設定の画面">

2. スマホのカメラで画面右の **QR コード**を読み、表示に従って `CWDEC-OTA` に接続します。
   QR が使えないときは、スマホの WiFi 設定で `CWDEC-OTA` を選び、パスワード `cwdecoder` を入れます。
3. 接続すると「ネットワークにサインイン」の通知 (または自動ポップアップ) から設定ページが開きます。
   開かないときは、ブラウザで `http://192.168.4.1/` を開きます。
4. 設定ページに自宅 WiFi の **SSID** と**パスワード**を入れて `保存` を押します。
5. 本体の画面に「WiFi設定を保存しました」と出て、SETUP 画面に戻ります。
   スマホは自宅の WiFi に戻してください。

- 本体 (ESP32) がつなげるのは **2.4GHz 帯の WiFi だけ**です。5GHz 専用の SSID は選べません。
- やめるときは本体の `キャンセル` を押します。登録した内容を消すときは [初期化](#初期化) を使います。
- 受信 (デコード) をしている間は WiFi を一切使いません。無線のノイズで受信を妨げないためです。

### FW自動更新

(既定 ON): 起動時 (スプラッシュの直後) に WiFi へ数秒だけ接続し、**NTP 時刻同期と
ファームウェアの新版チェックを 1 回の接続でまとめて** 行います。新版があれば画面に
`新しいファームウェアがあります v2.6 → v2.7` と出るので、`更新` / `キャンセル` を選びます。
`更新` を選ぶと GitHub Pages から自分のパネル用の bin を取得して書き換え、再起動します。
WiFi を登録していないとき、OFF にしたときは何もせず通常どおり起動します。
接続や取得に失敗しても、メッセージを出すだけでそのまま通常起動します

### FW更新

確認のうえ OTA モードへ (下の確認画面で `開始`)。本体が AP (`CWDEC-OTA` / パスワード `cwdecoder`) になり、
スマホ/PC を接続して `http://192.168.4.1/` から `firmware.bin` をアップロードします
(`tools/v<版>/firmware_<パネル>.bin`。無ければ `sh tools/make_release.sh` で作る)。
完了すると再起動します (途中で失敗しても旧ファームが残ります。戻るには再起動)。
WiFi を登録してあれば **AP と同時に自宅 WiFi にも接続 (AP+STA)** するので、PC のネットワークを切り替えずに
`http://cwdec.local/` (mDNS) でも更新できます。LAN 側の IP は画面の `LAN` 行に出ます

<img src="images/esp32-ota-confirm.png" width="320" alt="OTA モードに入る前の確認画面">&emsp;&emsp;<img src="images/esp32-ota.png" width="320" alt="OTA モードの画面">

左が確認画面、右が OTA モードの画面です。スマホとのつなぎ方は [WiFi設定](#wifi設定-最初に行ってください) と同じです
(AP は**キャプティブポータル**になっています。iPhone のサインイン画面ではファイル選択ができないことがあるので、OTA は Safari で開くのが確実です)。

### 時刻合わせ

▲▼ で年月日時分を合わせて `決定` (RTC は無いので電源を切るとビルド日時に戻ります)

<img src="images/esp32-timeset.png" width="320" alt="時刻合わせ画面">

- `夏時間`: 世界時計の夏時間を使うか (ON のとき各国の規則で自動計算)。押すとすぐ切り替わって保存され、
  表示中の時刻も新しい時差に合わせて動きます
- `NTP同期`: その場で NTP から時刻を取り込み、成功したら SETUP に戻ります (秒まで合うので `決定` は不要)。
  WiFi を登録していないときは灰色で押せません

### NR(ALE)

(既定 ON): ノイズ低減。ON で適応型ラインエンハンサ (ALE) を使うトーン検出になり、
弱い信号の感度が上がり、ノイズの偽文字が減る ([README の信号処理](../README.md#信号処理) 参照)。OFF で従来方式。
設定は NVS に保存され、次の起動でも同じ状態で始まる。OFF (従来方式) は入力レベルが高いと
局間の弱い信号を拾って正解率が下がるが、ON はレベルによらずほぼ一定

### タッチパネル調整

縦横 1/8 だけ内側に出る十字を4点タップして座標を校正します (端はベゼルが近く狙いにくいので
内側で測り、四隅の値は一次式で外挿します)。続く確認画面では 3 点の的を順に当ててもらい、3 点とも当たって
はじめて `[保存]` が押せます (上下逆のままの補正を「たまたま保存」できないようにするため)。
保存先は NVS (`cwdec` / `touchcal`、16 バイト) で、次回起動時に自動で適用されます。
`[やり直す]` で再校正、45 秒当たらなければ破棄して戻ります。`[既定に戻す]` で `src/lgfx_config.h` の既定値へ。

<img src="images/esp32-touchcal.png" width="320" alt="タッチパネル調整の開始画面">

**ズレた値を保存してしまったときの復帰**: `BOOT` ボタンを押したまま電源を入れ、そのまま 2 秒押し続けると
校正値を消して既定値に戻します (タッチを一切使いません)。タッチが効かなくなっても必ずこれで戻せます。
PC があれば、[USB 書き込みツール](https://pokibon3.github.io/cw_decoder4/flasher/) で同じ版を「設定を初期化」して書き直しても戻せます
(こちらは WiFi などほかの設定も既定値に戻ります)。
v2.6 でスプラッシュ下端の案内表示はやめた (画面からはみ出すうえ、その行を起動時の
時刻同期・更新状況の表示に使うため) ので、**復帰方法はここだけに書いてあります**。
なお 4 点が潰れているなど明らかに壊れた値は、保存時にも読み込み時にも弾きます

### 初期化

登録した SSID / パスワードを消去し、NTP 同期を止めます

### ログ出力

(既定 ON): スコープ画面の元データ (列ごとの min/max/エンベロープ/キー判定、デコード文字、
WPM/トーン、入力レベル) をシリアル (115200bps) にテキストで流します。Web アプリ等で画面を再現するためのもので、
送出は表示側 (Core 1) の非ブロッキング処理なのでデコーダには影響しません。行形式は `src/scopelog.h` を参照。
スコープビューア (<https://pokibon3.github.io/cw_decoder4/scope/>、ソースは `web/scope/index.html`) を Chrome で開くと、このログからスコープ画面を再現できます (保存したログの再生も可)。
受け手がいなければ捨てられるだけなので、常時 ON のままで構いません

## 操作

- ステータス行の `US`/`JP` バッジをタップ: 欧文 / 和文モード切り替え
- ステータス行の `TONE` ボタン (US/JP と同形) をタップ: AUTO → 600 → 700 → 800 → 900 → 1000Hz の順送り
  (AUTO は 500〜1000Hz の最強信号へ自動同調、緑色表示でデフォルト。
  1000Hz から AUTO へ戻したときは 600Hz から探し直す)
- FFT パネル内をタップ: タップ位置の周波数に最も近いトーンを手動選択 (AUTO 解除)
- FFT / オシロの波形部分を**ダブルタップ**: そのパネルを横幅いっぱいに広げる
  (もう一度ダブルタップで戻る)。掃引レートや周波数レンジは変わらないので、
  見える量がそのまま 2 倍になる。広げている間はもう一方のパネルは隠れる

  <img src="images/esp32-fft-wide.png" width="320" alt="FFT を横幅いっぱいに広げたところ">&emsp;&emsp;<img src="images/esp32-scope-wide.png" width="320" alt="オシロを横幅いっぱいに広げたところ">

- ステータス行の `SETUP` ボタンをタップ: SETUP 画面へ
- 文字エリアの中央付近をタップ: 時計画面へ切り替え (時計の中央をタップで戻る)

BOOT ボタンでも操作できます (短押し: トーン切替 / 長押し 800ms: モード切替)。
タッチ座標がズレる場合は SETUP の **タッチパネル調整** で合わせてください (結果は NVS に保存)。
校正しないときの既定値は `src/lgfx_config.h` の `TOUCH_ST7789` / `TOUCH_ILI9341` (パネルごと) です。
調整をやり直せなくなったときは `BOOT` を押しながら電源投入 (2 秒保持) で消去できます。

時計表示中もデコーダは裏で動き続け、受信した文字は溜まっているので、

## 時刻の同期

NTP 時刻同期 (WiFi を登録した場合) は **起動時 (FW自動更新が ON のとき)** と、
**時計画面を表示している間** に自動で実行されます。[時刻合わせ](#時刻合わせ) の `NTP同期` で手動でも同期できます
(時計画面では起動 15 秒後以降の初回、以後 24 時間ごと。失敗時は 1 時間後に再試行。
起動時に同期できた場合は次回を 24 時間後に繰り延べるので二重には走りません)。
同期中の数秒〜20 秒は無線ノイズを避けるため DSP を一時停止します。
**デコーダ画面では WiFi を一切起動しません。**
