## Wi-Fi

### 接続先の Wi-Fi に接続できない

**症状**

- 起動時に `WiFi に接続できませんでした` と表示されます。
- 時計画面に `同期失敗 1時間後に再試行` と表示されます。
- SETUP の [About](manual.md#about) で、`NTP` が `未同期` のままになります。

本体は接続に失敗した理由を区別せず、いずれの原因でも同じ表示になります。次の項目を順に確認してください。

**1. 5 GHz 帯の SSID を設定している**

本体 (ESP32) は **2.4 GHz 帯の Wi-Fi にのみ**接続できます。ルーターの 2.4 GHz 帯の SSID を設定してください。
多くのルーターでは、2.4 GHz 帯と 5 GHz 帯で別の SSID が用意されています (SSID の末尾が `-g` / `-a`、`-2G` / `-5G` など)。

**2. パスワードが誤っている**

パスワードは大文字と小文字を区別します。[Wi-Fi の再設定方法](#wi-fi-の再設定方法) に従って、設定し直してください。

**3. ルーターのバンドステアリングにより切断される**

ルーターの「バンドステアリング」(「スマートコネクト」などの名称の場合もあります) は、2.4 GHz 帯と 5 GHz 帯を 1 つの SSID にまとめ、
混雑の少ない帯域に端末を自動で振り分ける機能です。最近のルーターには、初期設定でこの機能が有効になっている機種があります。

この機能が有効な場合、ルーターが本体を 5 GHz 帯へ移動させようとして通信を切断することがあります。
本体は 5 GHz 帯に接続できないため、次のような症状になります。

- 接続に成功しても、数秒〜数分で切断されます。
- 認証に失敗し、接続を繰り返します。

次のいずれかで対処してください。

- ルーターの 2.4 GHz 帯専用の SSID を設定します。
- ルーターの設定画面でバンドステアリングを OFF にします (OFF にすると、2.4 GHz 帯と 5 GHz 帯の SSID が別になります)。
- 802.11k / v / r (高速ローミング) の設定がある場合は OFF にします。メッシュ Wi-Fi でも同様の制御が行われることがあります。

ルーターの設定方法は、ルーターの取扱説明書を参照してください。

**4. 電波が弱い**

本体をルーターに近付けて確認してください。金属製の棚や無線機の近くでは、電波が弱くなることがあります。

### CWDEC-OTA に接続できない

[Wi-Fi設定](manual.md#wi-fi設定-初回使用時) や [FW手動更新](manual.md#fw手動更新) で、スマートフォンまたは PC が本体のアクセスポイント
(`CWDEC-OTA`) に接続できない場合は、次の項目を確認してください。

**1. 誤った Wi-Fi 設定が残っている**

Wi-Fi が設定済みの場合、本体はアクセスポイントとして動作しながら、接続先の Wi-Fi にも同時に接続します。
設定したパスワードが誤っている場合や、接続先の Wi-Fi に接続できない場合は、本体が接続を繰り返すため、
`CWDEC-OTA` への接続が不安定になることがあります。

[初期化](manual.md#初期化) で Wi-Fi の設定を消去してから、もう一度接続してください。
初期化では、タッチパネルの調整値など Wi-Fi 以外の設定も消去されます。

**2. スマートフォンが別の回線に切り替わる**

`CWDEC-OTA` はインターネットに接続していないため、スマートフォンが自動でモバイルデータ通信や別の Wi-Fi に切り替えることがあります。
次の操作を行ってください。

- モバイルデータ通信を一時的に OFF にします。
- 「インターネットに接続されていません」と表示された場合は、接続を維持する操作を選択します。
- スマートフォンに保存されている `CWDEC-OTA` を削除してから、もう一度接続します。

**3. 本体から離れている**

スマートフォンまたは PC を本体の近く (1〜2 m 以内) に置いて接続してください。

### Wi-Fi の再設定方法

パスワードを誤って設定した場合や、ルーターを交換した場合は、次の手順で設定し直してください。

1. SETUP の `初期化` をタップし、確認画面で `初期化` をタップします。Wi-Fi の SSID / パスワードを消去します。
2. SETUP の `WiFi設定` をタップし、[Wi-Fi設定](manual.md#wi-fi設定-初回使用時) の手順で SSID とパスワードを入力します。
3. 本体の電源を入れ直します。起動画面に `WiFi に接続できませんでした` が表示されなければ、設定は完了です。
   SETUP の [About](manual.md#about) で、`NTP` に `11/28 09:15 同期済` のように同期した日時が表示されることも確認できます。
4. 初期化により、Wi-Fi 以外の設定も既定値に戻っています (消去する設定は [初期化](manual.md#初期化) を参照)。
   タッチ位置がずれる場合は [タッチパネル調整](manual.md#タッチパネル調整) を、そのほかの設定は必要に応じて設定し直してください。

手順 1 を省略すると、[誤った設定が残っている](#cwdec-ota-に接続できない) ために `CWDEC-OTA` への接続が不安定になることがあります。

## タッチパネル

### タップした位置と反応する位置がずれる

タッチパネルの特性には個体差があります。SETUP の [タッチパネル調整](manual.md#タッチパネル調整) で補正してください。
先端の細い器具を使用すると、正確に調整できます。

### SETUP ボタンをタップできない

タッチ位置が大きくずれて `SETUP` ボタンをタップできない場合は、次の手順で調整します。

1. 画面を押したまま電源を入れます。`そのまま押し続けると タッチ調整を始めます` と表示されます。
2. そのまま 2 秒間押し続けます。`指を離してください` と表示されたら指を離します。
3. 画面の四隅に順に表示される十字の中心をタップします。

30 秒以内に十字がタップされない場合は、調整値を変更せずに起動します。

### 調整後にタッチ操作ができなくなった

上記の手順でも操作できない場合は、PC の Chrome で [USB 書き込みツール](https://pokibon3.github.io/cw_decoder4/flasher/) を開き、
「設定を初期化」を実行してください。タッチパネルの調整値が既定値に戻ります。
Wi-Fi など、ほかの設定も初期化されるため、必要に応じて [Wi-Fi の再設定](#wi-fi-の再設定方法) を行ってください。

### タップしても反応しない、または触れていないのに反応する

- 画面の縁が筐体やケースで押さえられていると、触れていなくても押されている状態になることがあります。
  ケースのねじを締め過ぎていないか、保護フィルムが浮いていないかを確認してください。
- 指の腹で軽く触れると反応しないことがあります。指先や先端の細い器具で押してください。

上記で改善しない場合は、[タッチパネル調整](manual.md#タッチパネル調整) を行ってください。

## 設定

### SETUP の初期化で消去される設定

SETUP の `初期化` の確認画面には `WiFi の SSID / パスワードを消し` `NTP 時刻同期を止めます` と表示されますが、
実際には Wi-Fi 以外の設定も含め、本体に保存した設定をすべて消去します。

| 消去する設定 | 消去後の値 |
|---|---|
| [Wi-Fi設定](manual.md#wi-fi設定-初回使用時) (SSID / パスワード) | 未設定 |
| [タッチパネル調整](manual.md#タッチパネル調整) の調整値 | 既定値 |
| [FW自動更新](manual.md#fw自動更新) | ON |
| [NR(ALE)](manual.md#nrale) | ON |
| [デコーダ](manual.md#デコーダ) | DL |
| [時刻合わせ](manual.md#時刻合わせ) の `夏時間` | ON |
| [時計画面](manual.md#時計画面) で選択した国 | `JA` (日本) |

- 消去後の値は、次に電源を入れたときから適用されます。電源を切るまでは、消去前の設定で動作します。
  そのため、初期化の直後にはタッチ位置がずれず、電源を入れ直したあとにずれることがあります。
- 電源を入れ直したあとにタッチ位置がずれる場合は、[タッチパネル調整](manual.md#タッチパネル調整) を再度行ってください。
  `SETUP` ボタンをタップできない場合は、[SETUP ボタンをタップできない](#setup-ボタンをタップできない) の手順で調整します。
- 時刻と [ログ出力](manual.md#ログ出力) の設定は保存していないため、初期化の影響を受けません。
